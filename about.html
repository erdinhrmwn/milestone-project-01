About Our Project

We made this website because we love football. It is a place where you can see cards of famous players and collect them.

Our Mission

Our goal is to make a simple app for fans. We want everyone to be able to see their favorite players easily on their phone or computer.

How it started

This project was started for a bootcamp. We learned how to use HTML, CSS, and Javascript to make a working app. We hope you like it!

Tech Stack:

  • HTML for structure
  • CSS (Tailwind) for colors
  • Javascript for the game logic
  • LocalStorage for saving favorites
